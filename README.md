<h2 style="display: flex; align-items: center;">
  Features
  <span style="display: inline-block; width: 70px; height: 30px; overflow: hidden; margin-left: 8px; border: 1px solid white; vertical-align: middle;">
  <img
    src="https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcTCxQbu-Gmffp75RSRNVZhAjumc2I-CHQ3C1LTHcA6EluzKgsYKdikBSCA8&s=10"
    style="display: block; width: 70px; height: 40px; object-fit: cover; object-position: center;"
  />
</span>
</h2>

<p><i>everything essential...</i></p>

- Add income and expenses to any day in a calendar
- Categories and subcategories, with your own if the defaults don't fit
- Monthly totals: income, expense, what's left
- Charts: spending by category, income vs expense, month over month
- Recurring transactions — daily, weekly, monthly. Never auto-added; you approve each month
- Monthly budgets per subcategory, with progress
- PDF export of any month
- 7 languages, any currency

<h2 style="display: flex; align-items: center;">
  Andrid only
  <span style="display: inline-block; width: 70px; height: 30px; overflow: hidden; margin-left: 8px; border: 1px solid white; vertical-align: middle;">
  <img
    src="https://i.pinimg.com/736x/3b/87/e1/3b87e10ac70ba533456be9f690f967b9.jpg"
    style="display: block; width: 70px; height: 40px; object-fit: cover; object-position: center;"
  />
</span>
</h2>

<p><i>things that only make sense on a phone.</i></p>

- Fully offline. Data stays on the phone
- App lock (fingerprint, face, PIN, pattern)
- Home screen widget: today's spend, top budgets
- Share a payment screenshot (GPay, PhonePe, Paytm) — amount, name, date, UPI ref read on-device
- Smart category: learns which category you use per merchant (on device)
- Reminders: bills due, daily nudge, budget alerts at 80% and 100%
- Backup and restore via a file you save yourself

<p><i>// PERMISSIONS: internet, notifications, biometrics (each optional). No camera, mic, location, contacts, or SMS. Ever. Screenshots are read on-device, never uploaded.</i></p>
